以下是三种最简部署方案，选择一种即可。整个过程约需 10-20分钟。

🌐 方案一：GitHub Pages（推荐 — 免费、永久、零成本）

1
登录 github.com → 创建新仓库，命名为 shenzhen-air-ad（公开/私有均可）
2
将桌面上的 HTML 文件拖入仓库上传，上传完成后点击仓库 Settings → Pages → Source，选择 main 分支和 / (root) 路径，保存
3
等待2分钟后，访问 https://[你的用户名].github.io/shenzhen-air-ad/ 即可。分享此链接给同事，无需任何额外配置。

💡 进阶：如需更新数据，同事打开链接后，每次上传 Excel 文件即自动刷新本地数据（不需重新部署）。

⚡ 方案二：腾讯云 COS + CDN（国内访问最快，需腾讯云账号）

1
登录腾讯云控制台 → 对象存储 COS → 创建存储桶（选择深圳地域，公有读私有写）
2
上传 HTML 文件到存储桶根目录 → 开启静态网站托管功能 → 获取默认域名
3
开启 CDN 加速（可选），约¥0.2/GB流量。

🚀 方案三：Vercel（海外访问快、免备案、5分钟上线）

1
访问 vercel.com → 用 GitHub 账号登录 → New Project
2
上传 HTML 文件或连接 GitHub 仓库，Vercel 会自动识别并部署
